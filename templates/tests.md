## H. План `get_statistic`

Функция использует один материализованный CTE `delivered_orders`; базовая таблица `order` не читается отдельным коррелированным подзапросом для каждого ресторана. Нет `LATERAL` и лишних оконных функций. На восстановленной БД с `insert_test_data(10)`:

```text
Function Scan on get_statistic
actual time=8.136..8.136 rows=10 loops=1
Execution Time: 8.172 ms
```

Вердикт: OK.
